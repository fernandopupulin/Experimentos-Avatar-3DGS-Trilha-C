# Experimentos Avatar — Trilha C

Pesquisa de Fernando sobre **cabeças 3D Gaussian Splatting (3DGS) animáveis**. A pergunta central é como associar gaussianas a um modelo facial controlável para preservar aparência e identidade quando pose e expressão mudam.

## Relatório

Leia o [relatório da Trilha C](relatorio_trilha_c.md). Ele apresenta os nove trabalhos de referência, os gargalos técnicos, uma proposta de implementação e um protocolo de comparação com métricas e resultados a preencher após os testes.

**Estado atual:** revisão bibliográfica e plano experimental. Ainda não há resultados de implementação medidos neste repositório.
